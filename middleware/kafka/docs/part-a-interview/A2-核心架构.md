## 本章目标

能讲清 **Broker、Topic、Partition、Replica、Leader/Follower、Controller/KRaft** 的关系。

---

## 一、组件

| 组件 | 作用 |
|------|------|
| **Broker** | 存分区日志、处理 Producer/Consumer 请求 |
| **Topic** | 逻辑消息流 |
| **Partition** | Topic 的物理分片，并行与有序边界 |
| **Replica** | 分区副本，容错 |
| **Leader** | 分区读写入口 |
| **Follower** | 从 Leader 同步 |
| **Controller / KRaft** | 集群元数据、Leader 选举、分区分配 |

---

## 二、写入路径（简化）

```text
Producer
  → 选 Partition（Key 哈希或轮询）
  → 找 Partition Leader Broker
  → append 到 log segment
  → Follower 拉取同步
  → 按 acks 配置返回 ack
```

---

## 三、读取路径（简化）

```text
Consumer
  → 协调者分配 Partition
  → fetch 从 Leader
  → 处理消息
  → 提交 offset（自动或手动）
```

---

## 四、与 Pulsar 架构一句对比

| | Kafka | Pulsar |
|---|-------|--------|
| 消息体 | Broker 磁盘 | BookKeeper |
| Broker 故障 | ISR 内选 Leader | Broker 换机，数据在 BK |
