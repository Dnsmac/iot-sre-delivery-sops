# A7 保留与清理策略

> P1 必学 | 对齐 [pulsar/A7](../../pulsar/docs/part-a-interview/A7-保留与清理策略.md)

## 参数

| 参数 | 作用 |
|------|------|
| `retention.ms` | 消息最长保留时间 |
| `retention.bytes` | 分区最大字节 |
| `cleanup.policy=delete` | 到期删除（默认） |
| `cleanup.policy=compact` | 按 Key 压缩，保留最新值 |

## 与消费关系

- **delete**：到 retention 就删，**与消费者是否读到无关**（类似 Pulsar Retention 独立于 Cursor）。
- **compact**：适合 changelog（设备最新状态 Topic）。

## 面试句

> retention 满了旧消息会删，不是等 Consumer 追平才删；积压时要同时看 **lag 和磁盘 retention**。
