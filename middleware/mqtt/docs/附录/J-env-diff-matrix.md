# 附录 J：环境差异矩阵

> 开发 Mosquitto vs EMQX 预发/生产 vs 边缘网关；与 [B12](../02-开发篇/B12-environment-models.md) 一致。

---

## 三环境核心差异

| 维度 | 本地 Mosquitto | 预发 EMQX | 生产 EMQX (+K8s) | 边缘+云 |
|------|----------------|-----------|------------------|---------|
| **用途** | 功能/debug | 集成/压测签字 | 线上流量 | 工厂/楼宇汇聚 |
| **地址** | localhost:1883 | pre-mqtt.corp:8883 | mqtt.corp:8883 | 网关出网 TLS |
| **TLS** | 通常无 | 企业 CA | 企业 CA + 轮转 | 网关终止 |
| **认证** | 匿名可开 | 账号+ACL | 账号+ACL+mTLS可选 | 网关证书 |
| **连接规模** | <1K | 按比例缩容 | 10W 级 | 连接数=网关数 |
| **HA** | 无 | 2 节点起步 | 集群+LB | 网关本地 HA 可选 |
| **规则引擎** | 无 | 有 | 有 | 云侧为主 |
| **桥接** | 手动 bridge | Pulsar 预发 | Pulsar 生产 | 可边缘过滤 |
| **监控** | $SYS 可选 | Dashboard | Prometheus | 网关+云 |
| **压测结论** | 仅供参考 | **可签字** | 最终 SLO | 含缓冲延迟 |

---

## 配置项差异

| 配置键 | dev | pre | prod |
|--------|-----|-----|------|
| `mqtt.broker-url` | tcp://127.0.0.1:1883 | ssl://pre:8883 | ssl://prod:8883 |
| `mqtt.ssl.enabled` | false | true | true |
| `mqtt.clean-session` | true（常） | 与 prod 一致 | 按产品 |
| `mqtt.topic.prefix` | `dev/` | `pre/` 或 `prod/` | `prod/` |
| ACL 范围 | 宽或匿名 | 同 prod 结构 | 最严 |

---

## 行为差异（易踩坑）

| 行为 | Mosquitto 开发 | EMQX 生产 |
|------|----------------|-----------|
| 慢消费者 | 队列满可能丢 | 可配置丢弃策略+告警 |
| 鉴权失败 | 日志简单 | Dashboard 多维统计 |
| ClientId 冲突 | 易复现 | 踢人+遗嘱连锁 |
| 消息大小 | 默认限制 | 可能更严 |
| 共享订阅 | 不支持/有限 | 支持（扩展消费） |

---

## Topic / QoS 策略差异（应一致）

**原则：** 预发与生产的 **层级与 QoS 策略同构**，仅前缀或租户可不同（`pre/` vs `prod/`）。禁止开发随意 topic 上生产。

| 流类型 | QoS 建议 | 三环境一致？ |
|--------|----------|--------------|
| 遥测 | 0 | ✅ |
| 指令 | 1 + 幂等 | ✅ |
| 状态 retain | 1 + retain | ✅ |
| 遗嘱 | 1 | ✅ |
