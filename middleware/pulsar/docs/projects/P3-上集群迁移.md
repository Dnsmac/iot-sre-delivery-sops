## 阶段 A：准备 Cluster（运维）

- [ ] 3 ZK + 3 Broker + 3 Bookie（或团队最小拓扑）
- [ ] 创建 `company-stress` tenant / `app` namespace
- [ ] 配置 TLS + JWT（可与 prod 同结构）
- [ ] Prometheus 抓取 Broker/Bookie metrics

若无物理 Cluster，可用 Helm 在测试 K8s _NAMESPACE 部署。

---

## 阶段 B：应用配置切换（开发）

1. 新增 `application-stress.yml`：

```yaml
spring.pulsar.client.service-url: pulsar+ssl://stress-proxy:6651
app.pulsar.tenant: company-stress
app.pulsar.namespace: app
```

2. Token 从环境变量 `PULSAR_TOKEN` 注入  
3. **关闭** stress 环境 Auto-Create  
4. 用脚本创建与 dev 相同的 Topic 列表（分区数一致）

## 阶段 D：冒烟与压测

```bash
pulsar-client produce persistent://company-stress/app/health -m "ok"
pulsar-client consume persistent://company-stress/app/health -s smoke-sub -n 1
```

运行 `examples/java/pulsar-basics` 中 HelloPulsar，改配置指向 stress。

**可选：** 运行 [B11](../part-b-java-dev/B11-性能验证.md) 对比 dev vs stress 的 msgRate（签字用 stress 数字）。
