# 文档深度标准（Pulsar / MQTT 通用）

> 此前版本多为**提纲**（表格 + 一句话），不符合本标准。  
> 深化后的章节应达到下列最低要求。

## 每章最低结构

```markdown
# 标题
> 优先级 | 预计阅读时间

## 本章解决什么问题
## 面试常问（3~8 题）
## 核心知识（原理，含图/流程，非仅表格）
## 面试标准答案（至少 2 题写完整段落，可背诵改写）
## 生产环境注意点
## 与 XX 的差异（若适用）
## 易错点与反例（≥3 条，含「为什么错」）
## 动手验证（命令/代码/实验步骤）
## 相关章节
```

## 字数参考（中文）

| 类型 | 最低 |
|------|------|
| Part A 单章 | 1500 字 |
| Part B 写代码章 | 1200 字 + 可运行代码片段 |
| B9 单场景 | 400 字（现象/定位/解决/预防） |
| B10 调优章 | 2000 字 + 决策树 + 参数表 |
| Part D 单篇 | 600 字 |
| 附录面试题 | 每题：要点 + 3~5 句参考答案 |
