# C6 安全

> 优先级: **P3 运维** | 深度：批次 4 ✓

## 本章解决什么问题

生产启用 TLS、认证、授权，以及 Java/Spring 客户端如何带 Token。

---

## 一、三层安全

| 层 | 机制 |
|----|------|
| 传输 | TLS：`pulsar+ssl://` |
| 认证 AuthN | JWT / OAuth2 / mTLS |
| 授权 AuthZ | RBAC：produce / consume / admin |

---

## 二、TLS

Broker `broker.conf` / Helm：

- `tlsEnabled=true`
- 配置 certificateFilePath、trustCerts

客户端：

```java
PulsarClient.builder()
    .serviceUrl("pulsar+ssl://broker:6651")
    .tlsTrustCertsFilePath("/path/ca.crt")
    .build();
```

---

## 三、JWT 认证（常见）

```bash
pulsar-admin tokens create --role app-producer
```

```java
.authentication(AuthenticationFactory.token(jwtString))
```

Spring：见 [B8](../part-b-java-dev/B8-配置管理.md) 环境变量 `PULSAR_TOKEN`。

---

## 四、RBAC 示例

```bash
pulsar-admin namespaces grant-permission persistent://company/production \
  --roles order-service \
  --actions produce,consume
```

- 按 **namespace** 最小权限。
- 禁止应用使用 superuser token。
