# C5 监控告警

> 优先级: **P3 运维** | 深度：批次 4 ✓

## 本章解决什么问题

建立 Pulsar 生产可观测性：核心指标、告警阈值、工具链与 On-call 第一眼看什么。

---

## 一、工具链

| 工具 | 用途 |
|------|------|
| **Prometheus** | 拉取 Broker/Bookie/Proxy metrics |
| **Grafana** | 官方或社区 Dashboard |
| **Pulsar Manager** | Topic/订阅管理（可选） |
| **pulsar-admin** | 临时排障、stats |

---

## 二、核心指标与告警参考

| 指标 | 说明 | 告警思路 |
|------|------|----------|
| `pulsar_rate_in` / `out` | 入出速率 | 突降 50% 持续 5min |
| `pulsar_subscription_back_log` | 积压 | 持续增长 30min |
| `pulsar_storage_size` | 存储 | 异常暴涨 |
| `bookkeeper_server_ADD_ENTRY` P99 | 写延迟 | > 10ms |
| Broker JVM GC | Full GC | > 1/min |
| Bookie 磁盘 | 使用率 | > 75% 预警，85% 紧急 |
| 连接数 | Proxy/Broker | 接近上限 80% |

---

## 三、按角色面板

| 面板 | 关注 |
|------|------|
| 业务 Topic | msgRateIn/Out、backlog、unacked |
| Bookie | ADD_ENTRY、磁盘、RW 状态 |
| Broker | CPU、连接、cache |
| Geo | replication lag（若启用） |
