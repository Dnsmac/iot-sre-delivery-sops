# C10 故障 Runbook

> 优先级: **P3 运维** | 深度：批次 4 ✓

## 本章解决什么问题

On-call 第一时间：现象 → 确认 → 止血 → 根因 → 预防，并与 Part D 问题百科联动。

---

## 一、通用流程

```
告警 → 确认影响范围（单 Topic / 单 NS / 全集群）
     → 查 stats / metrics / 日志
     → 止血（限流、扩容、降级）
     → 根因修复
     → 复盘 + 监控阈值调整
```

---

## 二、场景表

| 故障 | 现象 | 第一动作 | 深入 |
|------|------|----------|------|
| **Bookie 磁盘满** | 写入失败、NotEnoughBookies | 扩盘、缩短 retention、trigger offload | [P11](../part-d-problems/P11-Bookie磁盘满.md) |
| **Backlog 暴涨** | lag 持续升 | 看 msgRateOut、扩 Consumer | [P4](../part-d-problems/P4-积压.md) |
| **Broker OOM** | GC、pod 重启 | 调 cache、降连接、unload 热点 | [P8](../part-d-problems/P8-内存溢出.md) |
| **单 Topic 不可写** | 仅部分失败 | 该 Topic stats、bundle、权限 | [P1](../part-d-problems/P1-消息丢失.md) |
| **全集群不可写** | 全部失败 | bookies -rw、ZK 健康 | C1/C3 |
| **消费停滞** | backlog 增、out=0 | Consumer connected? | [P4](../part-d-problems/P4-积压.md) |
| **元数据异常** | Topic 404 | ZK/Oxia 会话、Broker 日志 | C1 |
| **复制 lag** | Geo 延迟 | 带宽、replicator 状态 | C7 |
| **Schema 失败** | 客户端启动失败 | get-schema、兼容性 | [P7](../part-d-problems/P7-Schema问题.md) |
| **连接风暴** | 连接数打满 | Proxy、限连、查多 Client 实例 | [P6](../part-d-problems/P6-连接问题.md) |

## 三、命令速查

```bash
pulsar-admin brokers healthcheck
pulsar-admin bookies list-bookies -rw
pulsar-admin topics stats persistent://tenant/ns/topic
pulsar-admin topics stats-internal persistent://tenant/ns/topic
pulsar-admin namespaces policies persistent://tenant/ns
```

---

## 四、止血手段（优先级）

1. **扩 Consumer**（消费慢）
2. **限流生产**（磁盘/积压危急）
3. **临时调 retention**（需业务批准）
4. **隔离故障 Bookie**（替换节点）
5. **勿**手删 ledger 目录
