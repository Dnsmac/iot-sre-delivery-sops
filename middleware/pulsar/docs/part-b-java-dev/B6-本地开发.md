# B6 本地开发（Standalone）

> 优先级: **P2 开发** | 预计阅读 25 分钟 | 深度：批次 4 ✓

## 本章解决什么问题

在 Windows 本机用 Docker 跑起 Pulsar、创建 dev 租户、用 Admin 排障、跑 Java 示例与单元测试。

---

## 一、一键启动

```powershell
cd middleware\pulsar
.\scripts\standalone-up.ps1
.\scripts\setup-dev-tenant.ps1
.\scripts\verify-examples.ps1
```

| 脚本 | 作用 |
|------|------|
| `standalone-up.ps1` | Docker Compose 启动 Standalone |
| `setup-dev-tenant.ps1` | 创建 `persistent://dev/test` |
| `verify-examples.ps1` | 编译并冒烟示例 |

端口：**6650**（binary）、**8080**（HTTP Admin）、**8081**（部分 UI，视镜像而定）。

---

## 二、常用 pulsar-admin

```powershell
$admin = { docker exec pulsar-standalone bin/pulsar-admin @args }

# Topic 统计
docker exec pulsar-standalone bin/pulsar-admin topics stats persistent://dev/test/hello

# 窥探消息（不消费进度）
docker exec pulsar-standalone bin/pulsar-admin topics peek-messages persistent://dev/test/hello -s hello-sub -n 5

# 重置订阅（慎用：从头或跳过）
docker exec pulsar-standalone bin/pulsar-admin topics unsubscribe persistent://dev/test/hello -s hello-sub

# Namespace 策略
docker exec pulsar-standalone bin/pulsar-admin namespaces policies persistent://dev/test
```

## 三、Java 示例运行

```powershell
cd examples\java\pulsar-basics
mvn -q compile
mvn -q exec:java -Dexec.mainClass="com.demo.pulsar.ProducerDemo"
mvn -q exec:java -Dexec.mainClass="com.demo.pulsar.ConsumerDemo"
mvn -q exec:java -Dexec.mainClass="com.demo.pulsar.KeySharedConsumerDemo"
```

调优对比：

```powershell
cd examples\java\pulsar-producer-tuning
mvn -q exec:java -Dexec.mainClass="com.demo.pulsar.tuning.BatchCompareBenchmark"
```

## 四、单元测试（Testcontainers）

[`HelloPulsarTest.java`](../../examples/java/pulsar-basics/src/test/java/com/demo/pulsar/HelloPulsarTest.java) 需本机 **Docker Desktop** 运行。

- CI 无 Docker 时可 `@Disabled` 或 profile 跳过。
- 集成测试比 Standalone 脚本更接近「干净环境」。

---

## 五、Standalone 能做什么 / 不能做什么

| 能 | 不能 |
|----|------|
| ACK、DLQ、Schema、Key_Shared 功能验证 | 真实万级 QPS、连接数 |
| 学习 Admin、排障命令 | Bundle 迁移、多 Broker 负载 |
| 跑通 examples | 代替 Cluster 压测签字 |

详见 [B12](B12-环境模型.md)。

---

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 6650 拒绝连接 | `docker ps` 看容器是否 healthy |
| Topic not found | 跑 `setup-dev-tenant.ps1` 或手动 create |
| 中文路径问题 | 项目在纯英文路径更稳 |
