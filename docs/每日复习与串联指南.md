## 二、90 秒 IoT 全链路（W2 后主开场 · 背这一条）

**按现网讲**（卡壳回 `IoT全链路白板.md` 或 mqtt A2）：

```text
1. 【设备】MQTT 连 VIP:1883（MetalLB → iot-web 接入层）

2. 【Java】iot-server 处理鉴权/业务/转发 — 我负责 ______ 模块（W1 故事）

3. 【消息】上报进 Pulsar Topic → 消费者写 MySQL / Redis / ES

4. 【治理】连接满/积压时：限流、扩容、消费 lag — 见连接治理 / 稳定性 SOP

5. 【规模】平台 40 万级；压测我参与 ______ 段优化（W6 填，非 owner）

6. 【之前】电商/社区 ______（故事 #1 一句）
```

**自检**：W2 后能否 **90 秒** 不脱稿？每周五录音对照 [`学习路径`](../05-Interview-Prep/学习路径与面试串讲.md) §八。
