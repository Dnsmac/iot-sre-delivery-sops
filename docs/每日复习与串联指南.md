## 二、90 秒 IoT 全链路（主开场 · 背口述稿）

**主稿**：[`05-Interview-Prep/口述稿/W1-全链路.md`](../05-Interview-Prep/口述稿/W1-全链路.md) · 对照 [`IoT全链路白板.md`](../02-EMQX-IoT-Tuning/IoT全链路白板.md) §8

```text
1. 【设备】MQTT VIP:1883 → iot-web 透传 → iot-server 内嵌 MqttServer（JVM 线程）

2. 【上行】PUBLISH 解码 → EventBus → ES/MySQL/规则（不经 Pulsar 第一跳）

3. 【会话】TCP 在 Pod 内存；Redis connectionServerId 集群路由；下行 RPC 到持会话 Pod

4. 【Pulsar】级联等异步场景；压测协助级联 + Pulsar 调优（非 owner）

5. 【我】日常改 iot-server；模块细节 W4～W5 模块故事

6. 【之前】电商/社区 ______（故事 #1 一句）
```

**自检**：能否 **90 秒** 不脱稿？每周五录音对照 [`学习路径`](../05-Interview-Prep/学习路径与面试串讲.md) §八。
