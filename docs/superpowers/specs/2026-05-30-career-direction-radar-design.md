# 职业方向雷达设计（5min 主阅读 · 详情可选 · 2026-05-30）

> **学员定稿**：每周只要 **简约重点**；**详细放其他模块**，有兴趣再深挖。  
> **状态**：设计已定稿 → 待 `writing-plans` 后实施 `tools/industry-radar/`

---

## 1. Goal

每周程序跑采集 → 生成 **1 页 ≤5min 主文件**「值得考虑的方向 Top3」；详情、原始数据、锚点（含比亚迪）在 **独立模块**，默认不读。

**不是**：长 digest、6 块手工简报、副业实验作文。  
**是**：**本周占脑子的 3 条线 + 2 条别碰 + 1 行变化**。

---

## 2. 三层信息架构（强制）

```text
L1 主阅读（默认只看这个）     ≤5min
    05-Interview-Prep/行业雷达/方向/YYYY-W__.md

L2 详情（有兴趣再点）         5～15min / 方向
    05-Interview-Prep/行业雷达/详情/YYYY-W__/
        ├── 01-iot-isv.md
        ├── 02-byd-java-iot.md
        └── …

L3 原始数据（排查/复盘才看）  不看不算未完成
    tools/industry-radar/out/raw/YYYY-W__/*.json
```

| 层 | 读者 | 内容上限 |
|----|------|----------|
| **L1** | 每周必看 | **25～35 行**；表格 Top3 + 否决2 + diff1行 + 勾选 |
| **L2** | 可选 | 每方向 1 页：JD 样本、歧视占比、薪资分布、链接 |
| **L3** | 极少 | 全量 JSON |

---

## 3. L1 主文件固定模板（`方向/YYYY-W__.md`）

```markdown
# W__ 值得考虑（≤5min · YYYY-MM-DD）

## ① 本周只看这 3 条
| # | 方向 | 为啥值得看（1句） | 35+/专升本 | 动作 |
|---|------|-------------------|------------|------|
| 1 | … | … | 高/中/低 | 观察/只读JD/观望 |

## ② 本周别浪费时间（2条）
- …

## ③ 相对上周（1行）
- ↑ …  ↓ …

## ④ 下周主跟（勾1个）
[ ] 1  [ ] 2  [ ] 3  [ ] 都不跟，主轨IoT

---
深挖 → [详情/W__/README.md](详情/W__/README.md)（可选）
```

**动作枚举**：`观察` | `只读JD` | `观望` | `试投1个`（默认前三，不强制试投）

---

## 4. L2 详情模块（每方向 1 文件）

路径：`详情/YYYY-W__/{序号}-{slug}.md`

每文件 **≤80 行**，结构：

1. **结论**（与 L1 表格一致，1 句）
2. **数据**：岗位数、薪资 P25～P75、35岁字样%、统招本科%
3. **样本 JD Top 5**（标题+薪资+链接）
4. **与你画像**：1992、专升本、Java11y、IoT1y、目标25K — 匹配/硬伤
5. **锚点**：若含比亚迪，单独一小节「BYD 平台向 vs 嵌入式」

L1 表格 **禁止** 粘贴长 JD；只链到 L2。

## 5. 自动化（Playwright · 学员已选 A）

**入口**：`tools/industry-radar/run.py --week YYYY-W__`

**流程**：

```text
config.yaml（画像+搜索+锚点雇主 byd）
  → collectors（猎聘/BOSS 列表）
  → scoring（规则：岗量、薪资、歧视指数、栈匹配）
  → render L1 方向/YYYY-W__.md
  → render L2 详情/YYYY-W__/*.md
  → raw 写入 out/raw/（gitignore）
```

**`.browser-profile/`** gitignore；**L1/L2 可提交**（脱敏无个人信息）。
