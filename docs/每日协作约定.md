# 每日协作约定（Agent + 学员）

> **触发**：你不定时来问「今天干什么」「我进行到哪了」等 — Agent **必须先走本约定**，再排任务。  
> 规则文件：[`.cursor/rules/daily-coach-protocol.mdc`](../.cursor/rules/daily-coach-protocol.mdc)（`alwaysApply: true`）

---

## 一、Agent 收到「今天干什么」时的固定顺序

```text
① 读进度（PROGRESS_LOG 快照 + 当周手册勾选 + 口述稿勾选）
② 向学员确认：今天是否已做过 P0 / 今天实际学了多久（一句即可）
③ 输出：P0 第一事项 → P1 当日主任务 → P2 可选推进（≤1 条）
④ 禁止：未读进度就甩一整周计划；禁止一次列 >3 条主任务
```

**开场必须声明**：「先确认你当前阶段和今天进度。」

---

## 二、每日第一事项（P0 · 证据期 W1～W8 每天都做）

| 优先级 | 做什么 | 时长 | 验收 |
|--------|--------|------|------|
| **P0** | **口述稿读/录 1 遍**（当周主稿，见下表） | **10～15min** | 口述稿文末勾「今日已练」或 PROGRESS_LOG 记一行 |
| P1 | 当周手册 **下一个未完成 D?** | ~75min | 对应 Markdown 有新增/勾选 |
| P2 | 复习 7 问 / 外链 1 节 / 修白板 / **行业雷达特办**（≤30min，见 §2.1） | 剩余 | 可选，时间够再做 |

### 口述稿 P0 按周切换

| 周 | P0 文件 |
|----|---------|
| W1 | [`05-Interview-Prep/口述稿/W1-全链路.md`](../05-Interview-Prep/口述稿/W1-全链路.md) |
| W2 | 同上或 `W2-全链路.md`（生成后） |
| W3 | `W3-稳定性.md` |
| W4 | W1 全链路 **1 遍** + `W4-K8s.md` **1 遍** |
| W5 | `W5-模块.md` |
| W6～W7 | 当周主故事稿 + W1 全链路 **巩固 1 遍/周**（至少） |
| W8+ | 三故事串联稿 |

**原则**：P0 未完成 → **不新开** P1 大项（可只做 P0 就收工，不算犯规）。

### 2.1 特办：方向雷达（副轨 · 每周 ≤5min 阅读）

| 项 | 说明 |
|----|------|
| 跑脚本 | [`tools/industry-radar/run.py`](../tools/industry-radar/run.py) `--week YYYY-W__` |
| **只读 L1** | [`05-Interview-Prep/行业雷达/方向/YYYY-W__.md`](../05-Interview-Prep/行业雷达/方向/) |
| L2 可选 | [`行业雷达/详情/`](../05-Interview-Prep/行业雷达/详情/) |
| 时机 | 周五/周日 P2；**不抢** P0/P1 |
| Agent | 默认不排；学员说「方向雷达未做」或周日提醒 |

## 四、学员固定话术（复制即用）

### 早上 / 不定时 — 问今天干什么

```text
【今日开工】
日期：2026-__
我昨天/今天已做：（如：P0口述未做 / 已录W1第1遍 / JD雷达01写了半）
可用时间：__h
阻塞：（无/具体）
```

### 晚上 — 收工记账

```text
【今日收工】
P0口述：[ ]未做 / [x]已练 __min
P1主任务：__（手册 D?）
产出文件：__
明日接：__
```

Agent 收到 **【今日收工】** → 更新 `PROGRESS_LOG` 一行 + 建议改 **§当前快照**。

---

## 五、Agent 输出格式（问「今天干什么」时）

```text
## 进度确认
- 阶段：W? · D?（依据：……）
- 今日已知：……
- 待你确认：（若快照缺失，问 1 句）

## P0 第一事项（必做，~15min）
- …

## P1 今日主任务（~75min，仅 1 项）
- …
- 验收：……

## P2 可选（时间够再做 1 条）
- …

## 阻塞降级（3 条）
- …
```

## 七、学员维护（最小）

每天收工 **二选一**：

1. 自己改 [`PROGRESS_LOG.md`](../PROGRESS_LOG.md) §当前快照  
2. 发 **【今日收工】** 让 Agent 改  

**每周五额外**：P0 口述 **录音 1 遍** 存手机（不必上传仓库）。
