# 每日协作约定（Agent + 学员）

> **触发**：你不定时来问「今天干什么」「我进行到哪了」等 — Agent **必须先走本约定**，再排任务。  
> 规则文件：[`.cursor/rules/daily-coach-protocol.mdc`](../.cursor/rules/daily-coach-protocol.mdc)（`alwaysApply: true`）

---

## 一、Agent 收到「今天干什么」时的固定顺序

```text
① 读进度（PROGRESS_LOG 当前快照：phase / active_schedule / daily_budget / 今日P0 / open_gaps Top1）
② 打开 active_schedule 的当天日期行，只取当天 P0/P1/P2
③ 核对当天 P0 指定口述稿或题单的录音/练习留痕
④ 向学员确认：今天是否已做过 P0 / 今天实际学了多久（一句即可）
⑤ 输出：P0 第一事项 → P1 当日主任务 → P2 可选推进（≤1 条）
⑥ 禁止：未读快照就甩一整周计划；禁止叠加历史 W1/周手册任务；禁止一次列 >3 条主任务
```

**开场必须声明**：「先确认你当前阶段和今天进度。」

## 二、每日第一事项（P0 · SPRINT 每天都做）

| 优先级 | 做什么 | 时长 | 验收 |
|--------|--------|------|------|
| **P0** | **active schedule 当天指定的口述/题单读或录 1 遍** | **10～20min** | Markdown 记录日期、时长、卡壳点、下一步；不把未录音写成已完成 |
| P1 | 冲刺日历当天 **主任务 1 项** | 9 月通常 60～90min；10 月按当天预算；11 月起投递/面试动作 | 对应 Markdown、投递表或复盘日志有新增/勾选 |
| P2 | 当天可选补强或 Top1 gap 回灌 | 0～30min | 时间够再做；只回灌 1 个最高风险 gap |

### 阶段预算

| 阶段 | 预算 | 每日入口 |
|----|----:|----|
| 9 月收口 | 2h/天 | 冲刺日历 09-02～09-30 逐日行 |
| 10 月深度补洞 | 工作日 60～90min；周末/休假轻量日 30min | 冲刺日历 10-01～10-31 逐日题号 |
| 11-01～12-15 主投 | 40min 复习 + 投递/面试动作 | 冲刺日历主投期周表 + 星期模板 |

## 四、学员固定话术（复制即用）

### 早上 / 不定时 — 问今天干什么

```text
【今日开工】
日期：2026-__
我昨天/今天已做：（如：P0口述未做 / 已录W1第1遍 / JD雷达01写了半）
可用时间：__h
今日只看：PROGRESS_LOG 快照 + 冲刺日历当天
阻塞：（无/具体）
```

### 晚上 — 收工记账

```text
【今日收工】
日期：
P0口述：[ ]未做 / [x]已练；录音日期：____；录音时长：__min；卡壳点：__
P1主任务：完成/未完成；题号/章节：__
P2：完成/跳过：__
产出文件或记录：__
红线口误：无/有：__
Top1 gap：__
明天只回灌：__
```

Agent 收到 **【今日收工】** → 更新 `PROGRESS_LOG` 一行 + 建议改 **§当前快照**。不声称用户已完成未做录音/模拟。

```text
- 今日已知：……
- 待你确认：（若快照缺失，问 1 句）

## P0 第一事项（必做，~15min）
- …

## P1 今日主任务（~75min，仅 1 项）
- …
- 验收：……

## P2 可选（时间够再做 1 条）
- …

## 阻塞降级（3 条）
- …
```

## 七、学员维护（最小）

每天收工 **二选一**：

1. 自己改 [`PROGRESS_LOG.md`](../PROGRESS_LOG.md) §当前快照  
2. 发 **【今日收工】** 让 Agent 改  

**录音证据最小格式**：Markdown 至少写日期、录音时长、卡壳点、下一步。录音可存手机，不必上传仓库。

**gap 回灌**：每天只维护 `open_gaps Top1`。次日 P2 优先复测 Top1；不得为了 gap 打断当天 P0/P1 主线。
