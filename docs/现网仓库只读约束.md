# 现网仓库只读约束

> **硬规则**：`D:\gerrit\iot-server` 仅作 **阅读对照**；所有面试证据、SOP、白板 **只写本仓** `iot-sre-delivery-sops`。

---

## 两仓分工

| 仓库 | 路径 | 权限 | 用途 |
|------|------|------|------|
| **现网源码** | `D:\gerrit\iot-server` | **只读** | 查 `MqttServerDeviceGateway`、`DeviceSessionManager`、EventBus 等真实实现 |
| **学习/证据仓** | `d:\demo\iot-sre-delivery-sops` | **可写** | 白板、模块故事、JD 雷达、K8s 映射、口述稿 |

外链学习仓（`D:\demo\mqtt`、`pulsar`、`kafka`、`iot\IoT-Technical-Guide`）同样 **不在此约束内**，但 **不要** 把现网代码 patch 写进那些仓。

---

## 禁止事项

- 在 `D:\gerrit\iot-server` **改任何文件**（含 Cursor 自动改、格式化、生成代码）
- 在本仓 Agent 会话里 **git commit / push** 现网仓
- 把 **未脱敏** 的客户名、内网 IP、密钥、真实 topic 从现网仓复制进 Git 可提交文件（若必须引用类名，用代号）

---

## 推荐用法

### 读代码 → 写证据

```text
1. 在 D:\gerrit\iot-server 定位类/方法（只读）
2. 在本仓更新：
   - 02-EMQX-IoT-Tuning/IoT业务流程梳理.md
   - 02-EMQX-IoT-Tuning/iot-server模块故事.md（W4～W5）
3. PROGRESS_LOG 记「读了哪几个类、写了哪份证据」
```

### W4 模块故事

- **现象/改动/结果** 来自你的记忆 + 现网仓 **只读核对**
- **定稿文件** 只在 `02-EMQX-IoT-Tuning/iot-server模块故事.md`

规则文件：[`.cursor/rules/gerrit-iot-server-readonly.mdc`](../.cursor/rules/gerrit-iot-server-readonly.mdc)（`alwaysApply: true`）
