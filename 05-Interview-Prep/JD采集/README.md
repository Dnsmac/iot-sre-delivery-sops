### 采集动作（15-20min/天，碎片时间，不占 P0/P1 时间盒）

1. **搜索词轮换**（别用"Java 开发"）：`物联网平台` `设备接入` `AIoT` `机器人云平台` `云边端` `边缘计算` + `龙岗/深圳`。

3. **过滤四问**（任一不过直接跳过，不占库存）：
   - 学历硬门槛高于本科？→ 跳过
   - 标注 **"统招本科"**？→ 第一学历不达标则跳过（JD-16 类）
   - **纯 OD/外包岗**（如海柔 OD 岗）？→ 跳过，只收正编

5. **匹配分初评**（入库时打）：≥85% 主攻 / 70-84% 可投 / <70% 雷达不占 KPI。
6. **周日 P1 尾 15min**：批量重估本周新入库匹配分，同步 [`../投递跟踪表.md`](../投递跟踪表.md) 待筛选行。

| 2   | **MQTT**（接入/长连接/下发）                             | **12/13** | 懂协议机制 + 安全；很多写「必须精通」    | ✅ 内嵌 MqttServer；⚠️ 非 EMQX 调参    |

## 一句话：市场「最需要」的 TOP 5

```text
1. 你能证明「大规模设备接入 + 性能优化」有数字、有拐点、有长稳
2. 你把 MQTT 长连接 + 下行路由 + 持久化分工讲清楚
3. 你能在 MySQL / Redis / MQ 任一层定位线上瓶颈
4. 你有 JVM/并发层面的生产案例（OOM 或背压）
5. 你不是只会 CRUD —— 能讲接入层、时序、规则/消息边界
```

**你的主卖点排序**（对 13 份 JD 最大公约数）：

1. **GIIC 15W CoAP-TCP**（高并发硬数字）  
2. **iot-server 全链路**（MQTT + EventBus + ES/MySQL/Redis）  
3. **稳定性案例**（OOM / ES 写堵 二选一深挖）  
4. **11 年 Java** 垫在 IoT **1 年+** 前面（JD-12/07/10 最吃这套）
