## 稿（可照着录）

设备通过 **MQTT TCP 1883** 连到我们 **MetalLB VIP**，由 **iot-web 的 nginx 做 TCP 透传**，进到 **iot-server Pod** 里内嵌的 **MQTT 网关**。

连接时用 **clientId 当设备 ID**，从 **MySQL** 拿产品和密钥做认证。真正干活的 MQTT **TCP 长连接在 Pod 内存**里的 `localSessions`；同时往 **Redis** 写 `connectionServerId` 做集群路由，还可选落 **H2 文件**存元数据——但 **Pod 重启 TCP 还是要设备重连**。

设备 **PUBLISH** 之后，网关解码成 **DeviceMessage**，经 **DeviceMessageConnector 发到 EventBus**。持久化：**ES** 时序、**MySQL** 最新值和在线状态（有批量缓冲写）、**Redis** 还有限流和路由。

下行时，如果 API 打到 **没有该设备会话的 Pod**，会查 **Redis 的 connectionServerId**，经 **集群 RPC** 转到持有 TCP 的那台，再 **MQTT 下发**。
