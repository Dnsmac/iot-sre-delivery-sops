# 真实 JD 匹配度分析：机器人云平台 / IoT 平台方向（2026-09）

> 数据来源：猎聘 / 全职招聘网 2026年7-8月在招岗位，共 7 条真实 JD。
> 分析对象：5年+ Java，IoT（jetlinks/EMQX/Pulsar）、K8s 实战集群、麒麟离线交付、ERP 日峰值 3000 万。
> 核心问题：34+ 的年纪，面试官会不会要？

## 一、结论

- 7 条 JD 中 **5 条匹配度 ≥ 85%，直接可投**；2 条存疑（Go 偏好 / 领域知识缺口）。
- 34+ 本身不是减分项。减分的是"5 年纯业务 Java"的呈现方式。
- 高频共性要求 = 设备接入(MQTT) + 消息队列 + 时序数据库 + 云原生 + **线上故障排查**。前两项、第四五项你都是实战派；时序库是唯一硬缺口。

## 二、逐条匹配

### JD-1 蔚蓝智能·后端开发（机器人云端平台）｜南京 20-30K｜匹配 ~90%
要求：MQTT/gRPC、大规模设备接入、云原生(K8s/Docker)、MySQL/Redis/Kafka、监控告警体系、IoT 平台经验优先。
- 你的对照：EMQX 实战 ✅｜K8s 集群全链路 ✅｜Redis 集群/Pulsar ✅｜node4 监控体系自建 ✅｜jetlinks 平台经验 ✅
- 缺口：gRPC（半天可补）、OTA 分发细节。
- 判断：**直接约面级别**。

### JD-2 中电科数字·高级 Java 工程师(IoT 方向)｜上海｜匹配 ~88%
要求：MQTT 深入理解、EMQX/自研 Broker 调优、Kafka/EMQX、TDengine/InfluxDB、IoT 0到1、边缘计算框架优先。
- 你的对照：EMQX 生产调优 ✅｜Kafka 类经验(Pulsar) ✅｜IoT 全链路 ✅
- 缺口：TDengine 未用过；KubeEdge/EdgeX 未落地。
- 判断：**重点投递**。央企/军工背景 + 自主可控赛道，你的麒麟内网离线交付经验在这里是稀缺王牌，且对年龄宽容度最高。

### JD-3 AIoT 平台开发(车联网方向)｜匹配 ~88%
要求：3年+ Java/Go、Pulsar（明确列出）、EMQX、设备影子/OTA/边缘网关、K8s 云原生。
- 你的对照：**Pulsar 是你正在运维的中间件** ✅｜EMQX ✅｜K8s ✅
- 缺口：设备影子、OTA 固件升级流程。
- 判断：**直接约面级别**，Pulsar 这一项就刷掉 90% 候选人。

### JD-4 沐光机器人·机器人云端管理平台｜天津｜匹配 ~85%
要求：Spring Boot/Cloud、MySQL/Redis、时序库(InfluxDB/TimescaleDB)、MQTT/Kafka、Docker/K8s 部署、WebSocket、OTA 灰度发布、0到1 经历。
- 你的对照：全栈对得上，Docker/K8s 部署与稳定性是你强项 ✅
- 缺口：OTA 多版本灰度、时序库。
- 判断：可投，面试前把 OTA 概念 + jetlinks 设备网关对应关系理顺。

### JD-5 机器人管理平台 Java 后端｜北京丰台 15-25K｜匹配 ~85%
要求：JVM 调优、并发编程、MySQL/Redis、消息中间件积压/顺序消费、线上诊断、Netty/MQTT/Modbus 优先。
- 你的对照：**JVM + OOM 排查是你现在天天在做的事** ✅｜消息积压/可靠投递 ✅｜Linux 诊断 ✅
- 缺口：Netty/Modbus 细节。
- 判断：可投。薪资偏低但门槛友好，可作保底。

### JD-6 加速进化·云服务开发(机器人云平台)｜武汉 25-45K·15薪｜匹配 ~78%
要求：Go/Rust/Java/Python 任一、WebSocket/gRPC/MQTT、OTA/远程运维、容器化加分。人形机器人 A 轮公司。
- 你的对照：Java 通道存在 ✅｜IoT 平台经验是明确加分项 ✅
- 缺口：团队可能 Go 为主；50-99 人 A 轮创业公司，强度大。
- 判断：**存疑但值得聊**。薪资上限最高，用"平台从 0 搭建 + 稳定性"叙事去打。

### JD-7 通合科技·储能云平台 Java 后端｜西安 15-25K·13薪｜匹配 ~72%
要求：MQTT/Modbus TCP/IEC61850、BMS/PCS 对接、时序库、K8s、百万级设备接入。
- 你的对照：MQTT/协议适配 ✅｜K8s/排障 ✅
- 缺口：电力/储能领域知识（EMS/BMS/61850），这是硬门槛。
- 判断：**存疑**。除非愿意补电力领域知识，否则优先级放后。

## 三、共性缺口与 2 周补齐清单

| 缺口 | 出现频率 | 补法 | 工作量 |
|---|---|---|---|
| 时序数据库 TDengine/InfluxDB/ClickHouse | 5/7 条 | 把 kh-iot-server 遥测数据接一条 TDengine 链路（demo 即可），简历写上 | 1-2 周 |
| OTA / 设备影子 | 4/7 条 | jetlinks 物模型概念平移，理清"影子/期望值/灰度升级"话术 | 2-3 天 |
| gRPC | 4/7 条 | 上手一个 proto 服务，替换一次内部接口 | 半天-1天 |
| Netty/Modbus | 2/7 条 | 简历技能栏列出，面试前过一遍概念 | 1 天 |

## 四、34+ 的三个真实顾虑与应对

1. **"薪资要 25K，凭什么"** → 不讲工龄，讲稀缺交叉：IoT 平台 + K8s 集群运维 + 信创离线交付，三项同时具备的候选人极少。
2. **"能不能独立扛事"** → 用事实回答：node4 集群（MetalLB/Pulsar/Redis 集群/MinIO/ZLMediaKit 3副本）从部署到排障一人全链路；kh-iot-server OOM 根因定位到 jetlinks-supports 订阅表泄漏——这是面试里最值钱的 STAR 故事，务必练熟 3 分钟版本。
3. **"技术是否过时"** → 简历主动展示云原生 + 可观测性 + AI 辅助研发意识（有 JD 明确写了"落地 AI 辅助编程"）。

**投递优先级**：JD-2 中电科（信创王牌）> JD-3 车联网 AIoT（Pulsar 王牌）> JD-1 蔚蓝 > JD-4 沐光 > JD-6 加速进化 > JD-5 保底 > JD-7 视意愿。

**一句话定位**：不投"Java 开发工程师"，投"物联网/机器人云平台后端工程师"——同一个你，两种命运。
