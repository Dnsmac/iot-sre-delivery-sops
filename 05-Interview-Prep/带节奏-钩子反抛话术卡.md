# 带节奏话术卡（钩子 + 反抛 + 收口）

> **核心**：只把面试官引到真实做过、能讲数字和边界的锚点。没真实项目使用的题，明确说“了解级/官方变体”，不要硬钩。
> **事实源**：[数字与边界-唯一索引](数字与边界-唯一索引.md)；七维母稿：[面试连环深追脚本](面试连环深追脚本.md)。
> **主锚点**：GIIC 15W 压测、operatorCache OOM、EventBus/会话路由、ES NFS 写慢、ERP 幂等与状态机。

---

## 一、七维专用钩子

| 维度 | 钩子句 | 通向 |
|---|---|---|
| 业务场景 | 「这个我用 IoT 接入链路讲更真实：设备第一跳进 iot-server，解码后走 EventBus 分发。」 | IoT 主链路 |
| 并发 | 「并发题我会先讲有界队列和水位，GIIC 里有 per-connection `queue-size=32` 的复盘口径。」 | GIIC 背压 |
| MySQL | 「数据库正确性我不只靠锁，ERP 里用过幂等、唯一约束和状态机兜底。」 | ERP 副战场 |
| MQ | 「我们设备上报第一跳不是 Pulsar；Pulsar 我只讲级联、跨服务异步和长积压。」 | EventBus/Pulsar 边界 |
| 性能 | 「CPU 不高但慢，我会按 ES NFS 那次分层查，重点看 IO wait 和 bulk 积压。」 | ES 写慢 |
| 压测 | 「容量题可以按 GIIC 六算讲：连接、吞吐、带宽、存储、内存、机器/JVM/DB 档位。」 | 15W 六算 |
| 优化 | 「优化题我会用 5050 台设备 OOM 讲：加内存不是根治，有界缓存才是。」 | operatorCache OOM |

## 二、ERP 副战场钩子

| 场景 | 能讲 | 禁讲 |
|---|---|---|
| 订单/扣减/回调幂等 | 300+ 商户、日峰值约 3000 万、分布式锁、幂等、唯一约束、状态机 | 具体表结构、事故时间线、压测结果、收益百分比 |
| 秒杀/库存官方题 | 「我真实做过的是 ERP 幂等和防重复语义，秒杀库存分片属于官方变体。」 | 硬说做过秒杀大促或 Redis Lua 库存扣减实战 |
| MySQL 锁/事务追问 | 「唯一约束兜底、状态机控流转；具体 SQL 待本人补证。」 | 编造慢 SQL、索引、死锁事故 |

## 三、反抛句

| # | 反抛（背） | 用法 |
|---|---|---|
| R1 | 「这个我可以讲 30 秒概念，也可以讲一次 15W 压测实战，您想听哪个？」 | 开放题收敛到压测 |
| R2 | 「您是想听架构链路，还是想听一次线上排障？」 | 架构/故障二选一 |
| R3 | 「您是想听容量怎么算，还是想听瓶颈怎么定位？」 | 容量/性能二选一 |
| R4 | 「这个题如果按官方秒杀讲是一套，我真实项目更接近 ERP 幂等和状态机，要不要我按真实项目讲？」 | 把官方题拉回真实边界 |
| R5 | 「推荐/广告我只到了解级；如果您想看项目经验，我建议转到 IoT EventBus 扇出或设备影子最新态。」 | 弱绑定题降级 |

## 四、收口句

| # | 收口（背） | 用法 |
|---|---|---|
| C1 | 「这块我了解不深，生产里没直接做过；我可以讲通用机制，再说它和我做过的 `XX` 哪些地方相似、哪些不能类比。」 | 不懂题不硬撑 |
| C2 | 「这个数字我只能按假设反推，不能说成现网实测。」 | 容量估算防吹 |
| C3 | 「具体表结构和收益百分比我现在没有证据，不编；我能讲清机制和需要补什么证据。」 | ERP/MySQL 防编造 |

## 五、开场 30 秒

```text
我 11 年 Java，近年聚焦物联网后端。现在主讲 5 年+ Java 后端（IoT 平台）口径：
一条是 GIIC 15W CoAP-TCP 长连接压测参与，验收 5000 msg/s、96h 长稳；
一条是 iot-server 稳定性排查，比如 5050 台设备后 operatorCache 堆 OOM；
还有 ES NFS 写慢这类链路排障。业务兜底我会讲 ERP 的 300+ 商户、日峰值约 3000 万，
但只讲幂等、唯一约束、状态机这些已证机制。
```
