## 二、历史主线（按依赖顺序归档，不是每日入口）

### 主线 A —— 把素材变成故事（最大窟窿，P0）

**A1. iot-server 模块故事（IoT 主炮）**
- 为什么：简历第 1–3 条全押在 iot-server；你现在「改过链路、讲不清」= 主炮哑火。
- 填什么：按 `W4-W5_模块故事手册.md` §0 模板（边界 / 现象 / 排查 / 改动 / 结果 / 原理），用「GIIC r1–r8」当主故事线，类名从 `IoT业务流程梳理.md` 取。
- 去哪找：`D:\gerrit\iot-server`（只读）+ `GIIC-15万压测参与复盘.md` §3 时间线。
- 什么算完成：能 5 分钟不看稿讲出「我改了 X 类，从 A（~5k 挂）到 B（15W 长稳）」+ 1 个数字。

**A2. IoT 稳定性排查 SOP（故事 #3）**
- 为什么：面试必问「线上故障怎么处理」，你「排查做过、无 SOP」。
- 填什么：从 5 个 case 里选 1 个（首选 **operatorCache OOM**，其次 **ES NFS**），按「现象 → 排查命令 → 结论 → 方案/当前状态」串成一次完整排查。
- 去哪找：`02-EMQX-IoT-Tuning/cases/` 各 README + SOP 文件（OOM 案例已有 `SOP-现场诊断命令.md` + `SOP-MAT分析步骤.md`，直接抄）。
- 什么算完成：有「现象数字 + 3 条排查命令 + 根因 + 方案 + 当前状态」五段；OOM 必须说补丁待 Gerrit 合入、暂无复测收益。

**A3. 三故事口述稿 + 录音（P0，每天第一件事）**
- 填什么：`口述稿/W5-模块.md`（A1 定稿后）、`口述稿/W3-稳定性.md`（A2 定稿后）；`W1-全链路.md` 已有，保持每天读 1 遍。
- 什么算完成：每周五完整录 5 分钟，存档 `口述稿/`。

### 主线 B —— 场景题模板补全（你要的 Demo，P0）

**B1. 补全 GIIC 15W 容量 Demo 的缺失步骤**
- 缺 9 步（详见本轮回复「场景题诊断」，或直接看 §四）：
  `Step -1 场景登记表` / `题型分类` / `数字可信度分级` / `我的边界` / `坑点预警` / `口播三档` / `场景矩阵` / `收工动作指引` / `时间盒`。
- 什么算完成：每个数字有三态标记（硬数字/反推/假设/实测），有「边界」和「坑点预警」两段，口播分 30s/90s/深挖三档。

**B2. 用补全后的模板套第 2 个场景：20W MQTT 官方/假设迁移题**
- 填什么：明确“没做过 20W”，仅将 GIIC 六算迁移到 `[假设]` 的 200,000 连接、60s 上报、50k/节点等输入。
- 什么算完成：90 秒先报非经历边界，再讲假设、公式和待基线验证项；不引用 40W 复盘作证据。

**B3. 用模板套第 3 个场景：ES 写慢排查（故障型）**
- 填什么：把 `es-nfs-write-bottleneck` 案例套进模板（题型=故障排查，不是容量预估）。
- 什么算完成：能按「现象 → 分层定位 → 根因 → 建议」讲 2 分钟。

### 主线 C —— 概念防御（P1）

**C1. JD 雷达 7 篇：三行草稿 → 完整版**
- 填什么：每篇补全「定义 + 现网有没有 + 30 秒口播」三块（现在只有三行）。
- 优先级：**05-CoAP、07-Netty、01-物模型**（和简历最贴）先补，其余 4 篇收尾。
- 什么算完成：每篇能不看稿 30 秒说清「是什么 + 我们有没有 + 怎么答」。

### 主线 D —— 带节奏（贯穿全程，P1）

**D1. 钩子 / 反抛话术卡（10 句）**
- 填什么：从 A/B/C 的锚点各写 2–3 句钩子（「这本质跟 GIIC 压测的坑是一类——」），加 3 句反抛（「您想听架构还是排障」）。
- 什么算完成：每句背熟，能自然接在任意回答末尾。

**D2. 模拟面试 3 次**
- 填什么：随机抽 `面试题库-按简历倒逼.md` B 区 5 题 + 1 个场景题，计时口述。
- 什么算完成：3 次模拟中，2 次能不被带偏、主动引回锚点。

### 主线 E —— 电商降级为 P2 最小兜底（防翻车）

- 为什么留：历史材料记录 300+ 商户、3000 万日峰值和四类机制，但具体链路与结果待本人核对；只做 30 秒边界兜底。
- 填什么：说明历史材料范围、待核对项，并转到有证据的 IoT 案例；不背诵未经证实的防超卖链路。
- 什么算完成：被问 ERP 时不说具体接口/回调/消费端/状态流落点，不说“零超卖/零重复扣款”，当前不主动深讲。
