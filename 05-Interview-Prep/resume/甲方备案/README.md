# 甲方 / 外包备案版（不对外投递）

## 什么时候用

- 鸿讯、外包 HR 系统登记
- 需要与 **银行流水 / 劳务协议 / 个税** 主体完全一致时

## 文件位置

| 文件 | 路径 |
|------|------|
| 鸿讯存档（你已有） | `D:\鸿讯文件\java开发 - 骆峰.pdf` |
| 仓库旧稿参考 | [`../archive/`](../archive/) 中带日期的 HTML/PDF |

## 与投递版差异

| 项 | 投递版 | 备案版（鸿讯 PDF） |
|----|--------|-------------------|
| 2021—2024 ERP | 一家技术（合并一行） | 一家技术 2021.3—2022.9 + 谚礼 2022.11—2024.9 |
| 劳务说明 | 不写 | 谚礼行可标注「劳务协议」（仅备案系统） |
| 深开鸿 | 写深开鸿 | 按外包系统要求可能不同 |
| 用途 | Boss/猎聘/正式内推 | 外包平台、甲方 HR 备案 |

## 背调口述（两版通用）

> 2021～2024 年做同一 ERP 进销存平台。前期在一家技术全职带团队，后期远程续作，薪资主体换到谚礼，业务未断。投递简历合并写一家技术；若背调要流水，可按实际主体说明。

**不要**在对外 PDF 里写「无劳动合同」——那是备案系统内部备注。
