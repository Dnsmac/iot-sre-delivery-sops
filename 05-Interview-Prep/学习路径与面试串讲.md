## 二、面试开场优先级（5+ Java IoT 岗 · 按这个顺序练）

**错误顺序（旧）**：先讲 K8s 组件链 → 像运维/SRE，不像 Java 5 年+。  
**正确顺序（v3）**：

| 顺序 | 说什么 | 时长 | 何时能讲 |
|------|--------|------|----------|
| **1** | **我是谁**：11 年 Java，社区/电商 → 2025 IoT 平台 | 20s | 现在（画像 §叙事） |
| **2** | **现网干什么**：iot-server + K8s 上 ≈30 服务/中间件 | 30s | W4 后（模块故事定稿后） |
| **3** | **一条 IoT 链路**：设备→1883→iot-web→iot-server→Pulsar→DB | 60s | **W2 后（主开场）** |
| **4** | **一个拿手故事**：模块优化 / 稳定性排查 / 电商代表作 | 2min | W3/W5/W7 |
| **5** | **规模背景**：参与 40W 级压测，我负责 ×× 段 | 30s | W6 |
| **6** | **K8s 路径**（VIP/MetalLB/1883） | 60s | **W4 后（防守）** |
| **7** | **JD 雷达词**（物模型/OTA/时序…） | 各 30s | W7 前 |

### 2.1 HR 30 秒（背这个）

> 11 年 Java，做过社区和电商方向的高并发与架构；2025 年起在物联网平台项目，负责 Java 服务与 K8s 上中间件适配，参与过 **40 万级** 设备压测优化。求职 **资深 Java 后端 IoT 方向**，深圳 **25K 左右**。

### 2.2 技术面 90 秒（W2 后主力 · IoT 链路）

> 设备通过 **MQTT 1883** 连到 **MetalLB VIP** 上的 **iot-web**，进到 **iot-server**（Java），注册在 **Nacos**；上报走 **Pulsar**，落 **MySQL/Redis/ES**。我主要负责 **iot-server 上 ______ 链路**（W1 填）。协议上我在系统补 MQTT/Pulsar；压测我 **参与优化 ______ 段**，不是整场方案 owner。之前电商项目里 ______（故事 #1 一句）。

### 2.3 技术面 60 秒（W4 后 · K8s 防守 · 仅在被追问时）

> 见 [`每日复习与串联指南`](../docs/每日复习与串联指南.md) §K8s 串讲 — **不要当开场**。

## 三、知识面三层（怎么变成「自己的」）

```text
┌─────────────────────────────────────────┐
│ L1 现网故事层（本仓库 Markdown 证据）      │  ← 面试主材料，必须绑真实改动
├─────────────────────────────────────────┤
│ L2 原理补课层（D:\demo\mqtt / pulsar）   │  ← 回答「为什么这样配」
├─────────────────────────────────────────┤
│ L3 JD 雷达层（概念 + 现网有没有）          │  ← 猎聘高频词，每词 30 秒
└─────────────────────────────────────────┘
```

| 层 | 你要完成的动作 | 检验 |
|----|----------------|------|
| **L1** | 每个文件写：**现象→你的动作→结果（数字）** | 能指到仓库路径 |
| **L2** | 读外链 1 章 → 写 **1 句「我们现网是______」** 进 L1 文件 | 不被协议题打穿 |
| **L3** | JD 雷达每篇：**定义 + 有/无 + 30 秒** | W8 追问清单引用 |

**串联口诀**：**故事在 L1，原理用 L2 补洞，JD 词用 L3 挡枪。**
