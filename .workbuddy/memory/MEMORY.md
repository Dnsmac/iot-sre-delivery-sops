## 命名表达约定（2026-09-03 用户明确）
- **对外表述一律用「IoT 云平台」**，不说内部服务名 iot-server / kh-iot-server——"iot-server" 面试官听不懂，它本质就是 IoT 云平台（设备接入+物模型+EventBus+规则引擎）。
- 口述首提可带一句「内部服务叫 iot-server」；命令、源码路径、类名场景可念原名。
- 范围边界：口述稿/话术/画像/日历口径句 = 改成业务名；SOP/题库/场景题命令/源码路径 = 保留真实服务名作证据锚点。
- 完整映射表：05-Interview-Prep/数字与边界-唯一索引.md §0.5。
