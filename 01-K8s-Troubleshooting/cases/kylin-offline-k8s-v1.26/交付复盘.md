# 交付复盘 · 麒麟离线 K8s + 中间件

| 字段 | 内容 |
|------|------|
| 场景 | 实验室 / 准现场交付演练 |
| 现象 | 离线装簇与中间件（Redis/Pulsar）多次卡死；模拟断外网后 Spray/集群异常 |
| 影响 | 无法一次验收通过；阻塞中间件与后续业务 |
| 周期 | 2026-08 |

---

## 1. 目标

麒麟 V10 SP3 + K8s v1.26.4 **完全离线**交付：109 NFS/Spray、110 Harbor、105～108 节点；装簇后 Redis Cluster + Pulsar（固定 JWT）。

## 2. 排查主线（按时间）

1. **物料闭包**：装簇 yum 缺包 → 补齐 B03 至 71 RPM + preflight  
2. **导入验收误报**：Harbor push OK 但脚本 401 → 改为匿名 pull 验收  
3. **模拟离线网络**：OUTPUT DROP 漏网段；109 缺 Docker FORWARD/`ip_forward`  
4. **存储**：节点缺 nfs-utils → PVC/挂载失败  
5. **Pod 网络**：部分节点 restart kubelet 后 Redis Sandbox 丢网卡  
6. **Pulsar JWT**：只 apply token、缺 asymmetric-key；Helm pending-install 锁死  
7. **SSH**：lab 下发公钥成功但验证未带 `-i`  
8. **传包**：rar 截断 B08、CHECKSUMS CRLF、/tmp 满  
9. **中间件 SSH**：裸 ssh 反复要密码；客户只给私钥 → `ssh_node`  
10. **Pulsar 6443 refused**：装中间件时 restart kubelet 打掉 apiserver  

## 3. 根因（归纳）

| 层 | 结论 |
|----|------|
| 物料 | 离线包必须 **闭包+校验**；大包禁止半截 rar |
| 验收口径 | Registry **curl≠业务 pull** |
| 网络 | 模拟离线要放行 Pod/Service + Docker 桥；角色分流 |
| 运行时 | kubelet/CNI 生命周期不同步 → Sandbox 损坏；控制面勿乱重启 kubelet |
| 中间件 | Chart 约定的 Secret 必须齐；Helm pending 要解锁；SSH 必须走私钥 |
| 现场协作 | 客户私钥场景 ≠ 实验室自建密钥；公钥四台 + 私钥 109/105 |

## 4. 结果

- 脚本/文档迭代至 **v1.0.16**（见 `87\work`）  
- Redis/Pulsar 可达到 `deployed` + Pod Ready（修完 JWT/Sandbox/pending/6443 后）  
- 重装 checklist 写入交付手册「重装必读」  

## 5. 防复发（给下次实施）

1. 解压后：`wc -l` → **71 RPM**；`sha256sum -c`（先去 CRLF）  
2. `NIC_NAME` 与实机一致（本次 **ens18**）  
3. 装簇成功后再模拟断外网；109 用 **nfs-spray** 规则（含 FORWARD）  
4. 中间件安装期间 **禁止** 单节点 `restart kubelet`（用 B00 ≥1.0.16）  
5. Harbor 验收只认 **匿名 pull**  
6. 现场：客户私钥放 **109 + 105** → `verify-spray-ssh.sh`；公钥在 **105～108**；勿跑 lab-setup  
7. 换脚本只传 **B00 + CHECKSUMS**

## 6. 面试口径（30 秒）

> 做过麒麟离线 K8s 交付：分包物料闭包、Harbor 导入验收口径、模拟断外网时 Docker/FORWARD、以及 Calico Sandbox 损坏导致 Redis 重启、Pulsar JWT Secret 缺失。最后沉淀成 SOP 和版本化脚本，重装可一次过。
