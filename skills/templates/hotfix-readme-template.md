# Bug 修复说明（模板）

> **iot-server 约定**：每个 Bug 的 **合入主文档** 必须为本模板格式，路径：  
> **`bugfix-readme/hotfix_{BugId}-readme.md`**（例：`hotfix_37193-readme.md`）  
> `docs/cascade/级联BUG排查-*.md` 仅作 **技术归档**，文首须链接 hotfix 主文档。

> 与 Gerrit 提交规范对齐：Bug 修复类提交须关联 Bug 单号，提交描述格式建议为  
> `<hotfix><Bug单号>修复【模块】【子模块】【必现/偶现】简要标题`

---

## Bug ID

| 字段 | 填写说明 |
|------|----------|
| **Bug 单号** | 例如：`34876`（与提交 `<hotfix><34876>` 中单号一致） |
| **关联系统** | 例如：Jira / 禅道 / 内部缺陷平台（选填） |
| **Bug 链接** | （选填） |
