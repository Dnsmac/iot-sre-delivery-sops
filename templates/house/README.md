## 三、数据来源与接口

深圳统一地址库 `https://spatydz.sz.gov.cn/addrdatapc`（免登录，公众查询页背后的接口）：

| 用途 | 接口 | 关键参数 |
|---|---|---|
| 楼栋详情（地址 / 层数 / 坐标） | `/standard/search/buildingDetail` | `buildingId` = 19 位楼栋编码 |
| 楼栋长 + 网格员 | `/outerBuilding/queryByBuildingCode` | `code` = 19 位楼栋编码 |
| 模糊搜索（定位编码前缀） | `/standard/search/customSearch` | `query` / `region=440300` / `ak=d129375bf07f409a8e5d2ae232712b2a` |

**楼栋编码结构（19 位）**：

```
440304  004  008   03   00281
  区    街道  社区   段   楼栋序号（连续递增，从 1 开始）
```

- 上沙社区 = 第 3 段 `008`，下沙社区 = 第 3 段 `015`。
- 序号连续、不按巷号排序，**只能全量枚举**（本次每段扫 1~上界）。
- 段内会混入电房、祠堂、广场、学校等，已按名称剔除。

**联系方式解密**：楼栋长 `name`/`mtel`、网格员 `fullname`/`mobilephone` 为
**AES-128-ECB / Pkcs7** 密文，密钥 `FTKJ.2024`（不足 16 字节左侧补 `\0`）。
这两种身份的联系电话在官方小程序里本就对公众展示（带一键复制），
**仅供本人租房联系看房使用，请勿外传或另作他用。**

## 四、字段说明（CSV）

`序号 / 社区 / 村 / 巷-坊 / 门牌 / 层数 / 电梯推测 / 楼栋长 / 楼栋长电话 / 网格员 / 网格员电话 / 经度 / 纬度 / 楼栋编码 / 标准地址`

**层数口径**：≥11 层城中村基本配电梯；8–10 层需现场确认（部分已加装）；
<8 层一般无电梯，但**存在加装个例**（如龙秋村 7 巷 4 号官方 8 层、挂牌写明「独栋电梯房」）。
所以层数只作初筛，最终以现场为准。

## 五、已知边界

1. **62 栋查不到楼栋长**（约 4%），网格员覆盖更全（缺 31 栋）。
2. 电话有几个来源特征，非解密错误：
   - **座机**（8 位，如 `83444634`）多为村内管理处/房东固话；
   - **香港号**（`00852-` 开头）为下沙籍业主；
   - **一号多人 / 多号**已用 `、` 合并（原为「.」「/」「空格」分隔）；
   - 极个别 10 位号码为数据源本身录入不全。
3. 若某栋在上沙/下沙之间有**同名跨段**情况，以「标准地址」列为准。
4. 本清单**不含商品房小区**（如京基滨河时代），已按名称剔除。
